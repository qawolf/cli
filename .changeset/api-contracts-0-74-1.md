Upgrades `@qawolf/api-contracts` to `0.74.1`.

`qawolf run optOutOfInvestigation --run-id <id> --flow-ids <ids>` marks failed flows of a run as do not investigate (DNI). `qawolf run get` reports `failure.optedOutOfInvestigation` on a flow that a user or the system took out of the investigation.
