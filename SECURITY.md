# Security Policy

We take the security of `@qawolf/cli` seriously and appreciate responsible disclosure.

## Reporting a Vulnerability

Please report vulnerabilities through our [security portal](https://trust.qawolf.com/), which has contact information and security documentation for QA Wolf. Alternatively, you may open a private report using [GitHub security advisories](https://github.com/qawolf/cli/security/advisories/new).

Please do not disclose security issues publicly until we have had a chance to address them.

## Response Expectations

We aim to acknowledge new reports within a few business days and will keep you informed as we investigate and work toward a fix.

## Supported Versions

Security fixes are applied to the latest released version. We recommend staying on the most recent release to receive these updates.
